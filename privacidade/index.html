Política de Privacidade — Usina

Atualizado em 30/10/2026.

Dados coletados: apenas os tokens de acesso e as informações básicas de perfil (identificador e nome) das contas que o próprio dono conecta, necessários para publicar vídeos.

Uso: exclusivamente para enviar vídeos às contas do dono. Nenhum dado é vendido, compartilhado ou usado para outra finalidade.

Armazenamento: os dados ficam no computador do dono, em banco de dados local. Nada é enviado a servidores de terceiros além das próprias plataformas.

Exclusão: desconectar a conta na Usina ou revogar o acesso na plataforma apaga a autorização.
